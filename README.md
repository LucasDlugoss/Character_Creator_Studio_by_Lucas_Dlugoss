# Character_Creator_Studio_by_Lucas_Dlugoss
Character_Creator_Studio_by_Lucas_Dlugoss turns ComfyUI into a guided local 3D character production pipeline. Starting from a text prompt or uploaded reference views, it generates multi-view references with human-in-the-loop approval, builds a 3D mesh, bakes PBR textures, AI skeleton and skinning weights. and exports as an editable Blender file.
